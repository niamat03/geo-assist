GeoAssist
Description

GeoAssist est un plugin QGIS d'analyse géospatiale intégrée destiné à l'aide à la décision en aménagement du territoire. Il combine l'analyse vectorielle et la télédétection satellitaire au sein d'une interface unique.

Le plugin comprend deux modules :

GeoAssist Aménagement
Analyse de projets de dérogation forestière.
Calcul d'intersections avec les domaines fonciers.
Évaluation multicritère de l'éligibilité des projets.
Génération de rapports PDF et Word.

GeoAssist Sentinel
Téléchargement d'images Sentinel-1 et Sentinel-2.
Création de compositions multispectrales.
Calcul d'indices de télédétection (NDVI, NDWI, NDBI, RVI, etc.).
Visualisation et analyse des données satellitaires.

Technologies utilisées
Python
PyQt5
PyQGIS
GDAL
Rasterio
NumPy
ReportLab
python-docx

Installation
1. Copier le dossier GeoAssist dans le répertoire des extensions QGIS.
2. Activer le plugin depuis le Gestionnaire des extensions.
3. Redémarrer QGIS si nécessaire.
